# 5C-Nutrition-Pal
Tracking macros is easy at home with apps like MyFitnessPal, but nearly impossible in dining halls. 5CFitnessPal fixes that. We scrape the 5C menu sites daily and show calories, protein, carbs, fats, and fiber for every meal, so students and faculty can track exactly what they eat. Since students eat mostly on campus, tracking is finally simple.
